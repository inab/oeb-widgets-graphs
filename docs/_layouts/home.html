This is a collection of graphs made by OEB services. The graphs are made using the Plotly.js library.

Installation

To install the graphs, you can use the following command: 

npm i @inb/oeb-widgets-graphs
Usage
In JavaScript applications

Add the installed package to your javascript file. 

import '@inb/oeb-widgets-graphs';
Then you can use the graphs in your application. 
<widget-element id="widget-element"></widget-element>

In HTML applications (without a framework)

Add the installed package to your HTML file. 

<script src="https://cdn.jsdelivr.net/gh/inab/oeb-widgets-graphs@{{ site.demo_revision }}/dist/oeb-widgets-graphs.umd.js"></script>
Then you can use the graphs in your application. 
<widget-element id="widget-element"></widget-element>

const widget = document.getElementById('widget-element');
widget.type = 'bar-plot';
widget.data = JSON.stringify(graphData);

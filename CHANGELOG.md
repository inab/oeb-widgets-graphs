# Changelog

Notable changes are recorded here. Entries for releases before 1.2.0 are not
included; see the [GitHub history](https://github.com/inab/oeb-widgets-graphs/commits/main/)
and [releases](https://github.com/inab/oeb-widgets-graphs/releases).

## Unreleased

- Preserve package description, keywords, repository, homepage, issue tracker
  and author metadata in the distributable package.

## 1.2.0

- Added per-metric scale and bounds information to normalized radar plots,
  with linear and logarithmic scales and original values on hover.
- Improved scatter plot responsiveness, classification views and participant
  selection.
- Improved box plots with sorting, visibility controls and clearer table
  values.
- Improved bar plots with negative-value support, sorting and quartile
  classification.
- Improved line plots with shared-range AUC comparisons, visibility controls
  and configurable random-classifier baselines.
- Updated the demo, examples, documentation and package build.
